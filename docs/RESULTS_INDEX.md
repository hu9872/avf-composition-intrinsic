# Which file backs which claim

Every number in the manuscript is traceable to a file in `results/`. This index is the human
version of `results/provenance.csv` (which the assertion script generates and checks).

Machine-readable index: `python code/90_verify_numbers.py` rewrites `results/provenance.csv`
with one row per claim: `id, claim, source_file, expected_text, script, figure`.

## Files deliberately excluded from this repository

Large intermediate marker tables are **not** committed (>2 MB each, 400 MB total) because they
are fully regenerated by the pipeline:

- `s3_cluster_markers.csv` (126 MB) — `03_annotate.py`
- `s4_subcluster_markers.csv` (48 MB) — `04_fibro.py`
- `s5d_markers*.csv` (23–55 MB) — `05d_myeloid.py`
- `s5c_compartment_de_all.csv` (23 MB) — `05c_compartment_pseudobulk.py`
- `s5_pseudobulk_de.csv` (16 MB) — `05b_composition_pseudobulk.py`
- `s5e_cdc2_state_markers.csv` (8 MB) — `05e_cdc2.py`

Everything a reader needs to check a specific claim is either small and included, or one
`make` target away.
